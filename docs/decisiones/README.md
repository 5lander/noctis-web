# ADRs

Decisiones técnicas relevantes, numeradas e **inmutables**. Si una decisión cambia, se escribe un ADR nuevo que reemplaza al anterior; el viejo no se edita.

Plantilla: `docs/plantillas/ADR.md`. Ante la duda de si algo merece ADR, escríbelo.
